# SugApp Landing

Landing pública e interactiva de **SugApp — Soluciones digitales a medida**.

## Ejecutar localmente

No requiere instalación ni proceso de build. Abrí `index.html` directamente o iniciá un servidor local:

```powershell
python -m http.server 8080
```

Luego visitá `http://localhost:8080`.

## Antes de publicar

1. Definir el correo o canal de contacto público.
2. Agregar enlaces confirmados de WhatsApp, LinkedIn o GitHub cuando corresponda.
3. Reemplazar la imagen conceptual por capturas reales de Solitario Hunting.
4. Configurar dominio, analytics, URL canónica y metadatos sociales definitivos.

## Estructura

- `index.html`: contenido, SEO y estructura semántica.
- `css/styles.css`: sistema visual y responsive.
- `js/main.js`: navegación global, menú móvil y paneles desplegables.
- `js/demos.js`: tabs, renderizado e interacciones de las demostraciones.
- `js/demo-data.js`: contenido ficticio y configuración por actividad.
- `assets/images/`: recursos visuales.
- `POSITIONING.md`: interpretación comercial aplicada a la landing.
- `PROJECT_STATE.md`: estado vigente y contexto para continuar el proyecto.

El contenido de `SOM/SugApp/` se utiliza como fuente estratégica y no debe modificarse desde este proyecto.
